\begin{abstract}
Efficient inspection and visualization of measurement data is essential for iterative quantum device characterization, where experimentalists must rapidly assess results from complex multi-dimensional parameter sweeps.
Existing tools for browsing QCoDeS measurement databases suffer from long startup times, blocking interfaces, and limited interactivity, creating friction in high-throughput experimental workflows.
This work presents arbok-inspector, a browser-based Python application that provides lazy-loading database browsing, interactive multi-dimensional data visualization, and real-time analysis capabilities for quantum measurement data.
Built on NiceGUI and Plotly, the tool supports both QCoDeS SQLite databases and a native PostgreSQL/MinIO backend, enabling on-demand data exploration without loading entire databases into memory.
Each measurement run opens in an isolated browser tab with configurable dimension assignment, live averaging, histogram binning, and Fourier analysis.
The application integrates with the arbok-driver measurement framework and has been validated in production across multiple silicon spin qubit measurement campaigns.
\end{abstract}
